ciexifinfo
===========

Show the EXIF information embedded in a CI file.


Sample usage
------------

Show the EXIF info inside a CI file:

    ciexifinfo /path/to/file.ci

Show the EXIF info inside a raw `.exif` file, using base 16 for the EXIF tags:

    ciexifinfo --hex /path/to/file.exif

Show the help text:

    ciexifinfo --help
